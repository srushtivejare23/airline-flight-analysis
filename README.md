
# Airline & Flight Operations Analysis

## Project Overview
This project focuses on analysing airline operations and flight performance using PostgreSQL.

## Objectives
- Analyse airline and flight performance.
- Identify flight delays and cancellations.
- Study passenger booking trends.
- Analyse airline revenue and ticket pricing.
- Identify the busiest airports and flight routes.

## Tools & Technologies
- PostgreSQL
- SQL
- VS Code
- Git & GitHub

## Project Status
Currently in the initial setup and database design phase.
